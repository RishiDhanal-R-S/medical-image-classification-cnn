# Medical Image Classification using CNN

## Overview
This project implements a Convolutional Neural Network (CNN) model for medical image classification.
The model classifies medical images (like X-ray images) into Normal and Diseased categories.

## Features
- Image preprocessing and resizing
- CNN model training using TensorFlow/Keras
- Accuracy, Precision, Recall, F1-score evaluation
- Training performance visualization using Matplotlib
- Adaptable to different medical datasets

## Technologies Used
Python, TensorFlow, Keras, NumPy, Matplotlib, OpenCV, Scikit-learn
